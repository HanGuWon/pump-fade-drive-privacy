pump-fade-drive

pump-fade-drive is a private, single-user tool. It is not offered to the public.

Privacy policy

  • The app requests only the Google Drive drive.file scope. It can access only the files that it creates itself.
  • It uploads research data files produced by the owner's own server to the owner's own Google Drive.
  • It does not read other Drive files, and it does not collect, sell or share any user data with third parties.
  • OAuth credentials are stored only on the owner's server, with access restricted to the service account.
